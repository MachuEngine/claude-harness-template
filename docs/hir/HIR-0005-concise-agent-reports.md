# HIR-0005 — 서브에이전트 보고서를 짧게 고정

- 날짜: 2026-11-12
- 출처 프로젝트: Orbit (3~6단계)

## 문제
implementer·code-reviewer 보고서가 회차마다 수십~백여 줄이었다(명세 되풀이, 통과한 항목 나열, "확인한 항목" 목록). 메인 세션은 보고서 전체를 읽고 대화 기록에 남기므로, 단계가 길어질수록 메인 세션의 토큰 사용과 사용량 한도 도달이 반복됐다.

## 결정
두 에이전트의 보고 형식에 길이 목표(30줄·40줄)와 작성 규칙을 넣는다. 명세 되풀이 금지, 통과 항목은 숫자만, 문제없는 항목 나열 금지, 지적 하나 3줄 이내, 재검토는 해결 여부와 새 지적만.

## 대안
- 메인 세션이 보고서를 요약해 읽기: 도구가 결과 전체를 돌려주므로 효과가 없다.
- 리뷰 생략: 품질 위험이 커서 이번 범위에서 제외했다(위험도별 리뷰 조절은 별도 검토).

## 영향
보고서에서 판단 근거가 일부 생략될 수 있다. 메인 세션이 필요하면 해당 지적만 다시 묻는다.
