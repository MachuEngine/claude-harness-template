# HIR-0006 — 하네스 상태 표시줄

- 날짜: 2026-11-20
- 출처 프로젝트: Orbit (13단계 이후)

## 문제
긴 작업을 서브에이전트에 나눠 맡기면 메인 세션의 컨텍스트 사용량과 5시간·7일 사용 한도가 빠르게 찬다. 기본 화면에서는 이 값을 바로 볼 수 없어서, 한도에 가까워진 것을 작업이 멈춘 뒤에야 알게 됐다. 개인 전역 설정(`~/.claude`)에 만든 상태 표시줄은 다른 컴퓨터나 새 프로젝트에 따라오지 않는다.

## 결정
상태 표시줄 스크립트를 `.claude/harness/statusline.sh`(템플릿 소유)로 넣고, `.claude/settings.json`의 `statusLine`이 `$CLAUDE_PROJECT_DIR` 기준으로 실행한다. 4줄로 모델·effort, 컨텍스트 사용률과 토큰 수, 5시간·7일 한도 사용률과 초기화까지 남은 시간을 색상 바로 표시한다. 사용률 50% 이상은 노랑, 80% 이상은 빨강이다.

## 대안
- 개인 전역 설정만 유지: 이 컴퓨터에서만 적용되고 버전 관리가 되지 않는다.
- 스크립트를 프로젝트 소유로 두기: 프로젝트마다 복사본이 갈라진다.

## 영향
- 프로젝트 설정이 개인 설정보다 우선하므로, 하네스 프로젝트에서는 개인 `statusLine` 대신 이 스크립트가 표시된다. 바꾸려면 프로젝트 `.claude/settings.local.json`에 `statusLine`을 둔다.
- `jq`가 필요하다. 없으면 설치 안내 한 줄만 표시한다.
- 사용 한도 값은 구독 계정에서만 들어오며, 값이 없으면 해당 줄을 생략한다.
